# 🛡️ Моё тело — моя крепость!

Интерактивный обучающий кейс по профилактике преступлений против половой неприкосновенности несовершеннолетних.

## 🎯 Для кого
Дети 6–10 лет

## 📚 Что внутри
- 7 интерактивных заданий с игровыми ситуациями
- Озвучка голосом (с выбором голоса)
- Система баллов и сохранение прогресса
- Персонализированный сертификат эксперта
- Адаптивный дизайн (работает на телефонах, планшетах и компьютерах)

## 🧠 Темы, которые разбираются
- Правило купальника
- Хорошие и плохие секреты
- Границы тела и право сказать «НЕТ»
- Тревожные сигналы и «красные флажки»
- Круг доверия
- Правило «НЕТ → УЙДИ → РАССКАЖИ»
- Снятие чувства вины с ребёнка

## 🚀 Как запустить
Просто откройте файл `index.html` в любом современном браузере.

🌐 Онлайн-версия: [safety-case-kids](https://ВАШЕ-ИМЯ.github.io/safety-case-kids/)

## 💡 Методические особенности
- Безопасная лексика, адаптированная для детского восприятия
- Акцент на расширении прав ребёнка, а не на запугивании
- Вовлечение родителей через домашние задания
- Возможность проходить в комфортном темпе
